# Математика руками

Коллекция интерактивных примеров по математике.

Сайт: https://ivanblinov2k17.github.io/math-demos/

## Структура

```
index.html        каталог (читает catalog.json)
catalog.json      список всех примеров
<тема>/<пример>/index.html   сам пример, один самодостаточный HTML-файл
```

## Как добавить пример

1. Создайте папку `<тема>/<короткое-имя>/` (латиницей, через дефис), например `geometry/cone-volume/`.
2. Положите туда `index.html`. Внешние библиотеки (three.js и т. п.) подключайте с CDN.
   Добавьте в начало страницы ссылку назад: `<a href="../../">← Все примеры</a>`.
3. Добавьте запись в `catalog.json`:

   ```json
   {
     "path": "geometry/cone-volume/",
     "title": "Объём конуса",
     "summary": "Одно-два предложения о том, что показывает пример.",
     "topic": "Геометрия",
     "grade": "11",
     "tags": ["объём", "конус"],
     "added": "2026-10-08"
   }
   ```

4. Сделайте коммит и `git push`. Через минуту-две сайт обновится.

## Локальный просмотр

Каталог загружает `catalog.json`, поэтому открывайте его через локальный сервер, а не двойным кликом:

```bash
python -m http.server 8000
```

и затем http://localhost:8000
