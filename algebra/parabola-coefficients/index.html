Как коэффициенты меняют параболу

Угадай знаки

Появится случайная парабола, значения скроются. Определи знаки a, b и c по графику.

a
b
c

Коэффициент a

  • a > 0: ветви вверх, у параболы есть наименьшее значение.
  • a < 0: ветви вниз, есть наибольшее значение.
  • Чем больше |a|, тем уже парабола. При |a| < 1 она шире, чем y = x².
  • При a = 0 функция уже не квадратичная: график прямая.

Коэффициент b

  • Абсцисса вершины x₀ = −b / (2a).
  • a и b одного знака: вершина левее оси Oy.
  • a и b разных знаков: вершина правее оси Oy.
  • b = 0: вершина на оси Oy, парабола симметрична относительно неё.
  • b равно угловому коэффициенту касательной в точке (0; c).

Коэффициент c

  • Парабола пересекает ось Oy в точке (0; c).
  • Изменение c сдвигает график вверх или вниз, форма не меняется.
  • c = 0: парабола проходит через начало координат.
  • c / a — произведение корней (теорема Виета): при c/a < 0 корни разных знаков.
