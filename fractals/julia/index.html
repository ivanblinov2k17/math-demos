Выберите c на карте Мандельброта

Формула и раскраска

Степень p в zp + c2

Что это

Теперь число c зафиксировано, а меняется начальная точка. Для каждой точки z₀ плоскости повторяем:

z₁ = z₀² + c, z₂ = z₁² + c, …

Точки, чьи последовательности не улетают в бесконечность, образуют заполненное множество Жюлиа. На картинке оно тёмное, а его граница и есть множество Жюлиа.

Каждому c соответствует своё множество. Главное правило: если c лежит в множестве Мандельброта, множество Жюлиа связно, то есть состоит из одного куска. Если c снаружи, оно рассыпается в «пыль» из бесконечного числа точек.

История

  • 1915Гастон Жюлиа, 22 года, тяжело ранен на фронте Первой мировой и теряет нос. Всю жизнь он носит кожаную повязку на лице. Часть работы он пишет в госпитале.
  • 1918Выходит его «Мемуар об итерации рациональных функций» почти на 200 страниц. Французская академия наук присуждает ему Большую премию. Почти одновременно те же вопросы изучает Пьер Фату.
  • 1920-е–1970-еБез компьютеров увидеть эти множества нельзя, и о них почти забывают.
  • 1980-еБенуа Мандельброт, учившийся в Политехнической школе, где преподавал Жюлиа, строит множества на компьютере. Теория Жюлиа и Фату оживает.

Знаменитые c

c = 0: окружность |z| = 1гладкая c = −2: отрезок [−2; 2]прямая c = −0,123 + 0,745i: «кролик Дуади»связно c = i: «дендрит», дерево без площадисвязно c = 0,36 + 0,1i: «пыль Фату»не связно

Кролик назван в честь Адриена Дуади, который вместе с Джоном Хаббардом построил большую часть современной теории этих множеств.
