Типичные сечения

Задача

Памятка

Сечение

Сечение — многоугольник, по которому плоскость режет куб. Каждая его сторона лежит на одной грани куба.

n = число граней куба, которые пересекает плоскость

У куба 6 граней, поэтому сечение бывает треугольником, четырёх-, пяти- или шестиугольником. Две стороны сечения на параллельных гранях параллельны.

Грани части

F = (граней куба, задетых частью) + 1

Плюс один — само сечение: оно становится новой гранью у обеих частей.

Если плоскость не проходит через вершины куба, каждая из n разрезанных граней достаётся обеим частям, а остальные 6 − n целиком одной из них:

F₁ + F₂ = n + 8

Вершины части

V = (вершин куба по эту сторону) + n

Все вершины сечения — вершины обеих частей. Вершины куба, лежащие в самой плоскости, уже входят в n, их не считают второй раз.

V₁ + V₂ = 8 + 2n (если плоскость не идёт через вершины куба)

Рёбра: формула Эйлера

Для любого выпуклого многогранника:

V − E + F = 2 ⇒ E = V + F − 2

Удобно для проверки: посчитали грани и вершины, рёбра получаются сами. Для куба: 8 − 12 + 6 = 2.

Как решать задачу

  1. Постройте сечение: соедините точки, лежащие на одной грани, и продолжите линии до рёбер.
  2. Посчитайте стороны сечения: это n.
  3. Для каждой части посчитайте вершины куба по её сторону.
  4. Грани: перечислите грани куба, которые задевает часть, и прибавьте 1.
  5. Проверьте по формуле Эйлера.
